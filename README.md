# NETHEN v0.2
Aubrey's playable iPad-friendly web game prototype.

## v0.2 changes
- Character parts now change shape, not only colour
- Six distinct weapon styles
- Visible first-person weapon
- Lava Monster has telegraphed attacks
- Timed blocking and useful dodging
- Attacks require range + aim
- Physical Ember Meat drops must be collected
- Meat heals and charges Special
- Proper death screen with Retry / Character Creator / Main Menu
- Victory flow with replay / creator / menu
