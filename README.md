# NETHEN v0.1

Aubrey's playable iPad-friendly web game prototype.

## Included
- Nethen title screen
- Fighter creator with head, hair, armour, shoes, weapons and search
- Randomize + fighter name
- First-person 3D Nethen arena
- Lava Monster enemy
- Attack / Block / Dodge / Special controls
- Health + Special HUD
- Inventory
- Monster drops Ember Meat
- Eating meat restores health and charges Special

## Run locally
Because the game uses JavaScript modules, serve the folder with a local web server rather than double-clicking index.html.

Python example:
`python -m http.server 8000`
then open `http://localhost:8000`.

## Deploy
Upload the contents of this folder to a static host such as GitHub Pages, Netlify or Cloudflare Pages.
